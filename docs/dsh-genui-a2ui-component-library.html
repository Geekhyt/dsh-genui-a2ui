三、A2UI 1.0 Express 六条核心语法铁律（编译零报错指南）

1. 唯一根节点 root
每个 surface 必须且只能有一个 root = ... 入口变量；多个顶层区块请用 root = Card(Column([...])) 收拢。
2. $/path 只存纯 JSON 字面量
✅ 正确：$/wan = 200，公式赋给局部变量 pay = calc(...)。
❌ 禁止：$/pay = calc(...)（数据模型不存储函数 AST）。
3. weight 仅限 Row/Column 直接子项
只有放在 Row([...]) 或 Column([...]) 数组里的直接子组件才可写 weight=1；切勿在 root 或 Card 内部单子节点上写 weight。
4. ChoicePicker 必用具名参数
因第 2 个位置参数是 variant 而非 options，务必写 ChoicePicker(label=..., variant=..., options=[...], value=$/sel)。
5. 算术一律收拢进 calc()
A2UI 协议硬限 MAX_FUNC_CALL_DEPTH = 5；用 calc("pmt(r/1200, y*12, w*10000)", vars, 2) 保持嵌套深度恒为 1。
6. Thin UI, Thick Agent 职责边界
前端 calc/cond 负责 0ms 确定性交互算术；涉及实时外部查询、复杂多步推演或数据库写入，一律走 Event(...) + update=true。
